# HR-Analytics Dashboard
# 1. Project Title
Interactive HR Analytics Dashboard in Power BI

# 2. Project Description
This project involves building a comprehensive HR Analytics Dashboard from scratch to help organizations turn raw employee data into actionable business insights.
The dashboard provides a high-level overview of workforce demographics, attrition trends, and employee engagement levels.
Example Insight: By using the interactive visuals, HR teams can pinpoint specific problem areas; for instance, the dashboard might reveal that the Administration department has the highest attrition rate at approximately 36%, or show exactly how attrition is distributed across different salary slabs, such as identifying high turnover in the 6–10 LPA range
.
# 3. Tech Stack
* Power BI Desktop: Used for report designing and data visualization
* Power Query: Utilized for data cleaning, transformation, and standardizing inconsistencies
* DAX (Data Analysis Expressions): Employed to create powerful custom measures like Attrition Rate %
* Data Source: Structured HR data in CSV/Excel format containing 1,481 rows and 37 columns of employee information

# 4. Features / Highlights
* End-to-End Data Cleaning: Processes include removing null values and duplicates, fixing spelling inconsistencies (e.g., standardizing "travel_rarely"), and correcting data types to ensure calculation accuracy.
* Key Performance Indicators (KPIs): Real-time tracking of Total Employees, Active Employees, Attrition Count, Attrition Rate %, Average Age, and Average Experience.
  
* Interactive Visualizations:
- Attrition by Department: A donut chart to track which departments lose the most talent.
- Attrition by Salary Slab: A clustered bar chart to analyze how pay affects retention.
- Employee Satisfaction Heatmap: A matrix visual with conditional formatting to correlate job roles and satisfaction with attrition
- Workforce Demographics: Charts for Age Group Distribution and Gender-based Attrition.
- Trend Analysis: An area chart showing Attrition Trends by Experience to identify if turnover happens early or late in careers
- Dynamic Filtering: Includes interactive Slicers for Department and Age Group, allowing users to filter the entire dashboard with a single click.
